A StatefulSet (so each MySQL Pod keeps a stable identity).

A PersistentVolumeClaim (PVC) so the database doesn’t wipe on restart.

A Service so Laravel Pods can connect to it.

RoadMap:

Create a PersistentVolumeClaim → stores MySQL data on disk (so it survives Pod restarts).
Create a Deployment with 1 MySQL Pod (simple for now).
Create a Service so other Pods (like Laravel) can connect via mysql-service
